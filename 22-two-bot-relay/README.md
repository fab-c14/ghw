# Two-bot launch relay

Source Editor built a brief for SwampHacks XII from https://www.mlh.com/events. The announcement constraints were students looking for an in-person hackathon, a plain factual tone, and a call to action to read the event page before deciding whether to go. After the brief was approved, Source Editor invoked Launch Producer in the same chat. Launch Producer returned a 149-word announcement and a six-row run of show. Nothing was sent or published.

Source Editor compared both files with the brief. One saved status still said Pending after approval, so that single fix went back to Launch Producer. The saved run of show now marks that row Done. `qa-notes.md` says Pass.

The shared `launch-desk` folder holds `source-brief.md`, `announcement-draft.md`, `run-of-show.csv`, and `qa-notes.md`.
