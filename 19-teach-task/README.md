# City weather check

The City weather check skill opens a public weather page for one city and reports today's high and whether rain is expected. The city changes each run. This run used Delhi: about 34°C, rain not expected, chance 1% to 5%, from wttr.in.

The Weekday city weather routine runs that skill every weekday at 7:30am and shows the result in this chat. It does not send or submit anything.

The Teach Task control was not on this screen, so Daily Assistant created the skill and the routine from the chat.
