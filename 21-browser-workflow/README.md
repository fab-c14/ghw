# Weekend campus events

Daily Assistant learned a browser skill named Weekend campus events. The input that changes each run is the weekend. It opens https://www.mlh.com/events, records the source URL and check time, and returns up to five events. If nothing matches, it says no matches instead of guessing. It stops if the page is blocked or asks for a sensitive action, and it does not register, book, send, or purchase.

The first run used the weekend of 16 to 18 October 2026. The second run used 23 to 25 October 2026 and saved browser-workflow-result.txt. I checked Cal Hacks 13.0 against that page: Oct 23–25 in San Francisco, California, US.

Teach a Task was not on this screen, so the skill was written from the completed browser task.
